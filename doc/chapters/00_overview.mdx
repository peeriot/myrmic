# Overview

Myrmic is an open source edge-native runtime for building and operating distributed applications across fleets of devices. It runs application logic as WebAssembly cells - portable, isolated units that deploy and self-organize across embedded, mobile, and server targets without orchestrators, brokers, or manual wiring. The project is developed and maintained by [Peeriot](https://peeriot.io/).
