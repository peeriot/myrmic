# zenoh-traits

An implementation-agnostic traits for for working with the [Zenoh]() protocol.

In addition to the traits, this crate contains the follow two modules:
- `zenoh_traits::embassy` - an implementation of the traits for the `zenoh-nano` baremetal crate
- (Future) `zenoh_traits::zenoh` - an implementation of the traits for the `zenoh` STD crate
